# viaplay-cli Documentation

Welcome to the documentation for **viaplay-cli**! This documentation covers installation, configuration, usage examples, and best practices for using viaplay-cli.

---

## Overview

`viaplay-cli` is a command-line tool for scaffolding, configuring, and managing project repositories with support for templates, secrets, rulesets, and more. It is designed to streamline the process of creating and maintaining repositories, especially for teams and organizations.

- GitHub repository creation and configuration
- Secret management
- Template caching for remote repositories
- Hooks for pre/post project creation
- Rich template variables and functions

## Raw Files (no rendering)

To copy a template file verbatim, append the `.raw` suffix. The file will be copied as-is and the `.raw` suffix is removed in the generated project.

Example: `template.go.tmpl.raw` is copied to `template.go.tmpl` with no rendering applied.
