# viaplay-cli Documentation

Welcome to the documentation for **viaplay-cli**!

---

## Overview

`viaplay-cli` is a command-line tool for scaffolding, configuring, and managing project repositories with support for templates, secrets, rulesets, and more. It is designed to streamline the process of creating and maintaining repositories, especially for teams and organizations.
